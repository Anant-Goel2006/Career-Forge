# Coding Style
TypeScript: ESLint/Prettier, PascalCase components, camelCase functions, strict types, Zod boundaries.
Python: Ruff, mypy, snake_case functions, PascalCase classes, Pydantic contracts, repository/service/router separation.
Git prefixes: feat/, fix/, security/, docs/, refactor/.
Commit: type(scope): summary.
Keep modules small, composable and tested.
