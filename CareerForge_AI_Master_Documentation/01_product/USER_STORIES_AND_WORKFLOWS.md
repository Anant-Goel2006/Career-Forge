# User Stories & Workflows

## Upload
User uploads PDF/DOCX → client validation → server signature/MIME validation → private storage → parsing → evidence extraction → resume audit → editable profile.

## Tailor
User supplies JD → requirements extracted → candidate evidence retrieved → deterministic match → AI proposes wording → evidence validator checks claims → layout engine renders → document QA → user preview/export.

## RAG assistant
Question → retrieve relevant candidate/job evidence → treat retrieved content as untrusted data → generate grounded response → validate/cite evidence.

## Outreach
Select job → discover public professional contacts from approved sources → relevance/confidence → draft → user review → manual/user-initiated sending.

## Stories
- Upload and correct parsed resume.
- See resume mistakes and fixes.
- Paste/upload job.
- See required vs preferred requirements.
- See evidence for every matched requirement.
- Tailor resume for one opening.
- Export editable DOCX/PDF.
- Track versions and applications.
