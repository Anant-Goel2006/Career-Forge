# Acceptance Criteria
Upload: PDF/DOCX accepted; invalid/oversized files rejected; progress/errors shown.
Audit: mistakes grouped by severity; explanations shown; no invented claims.
Tailoring: requirements visible; evidence mapped; unsupported skills excluded; role/level affects wording; one-page output.
Export: editable DOCX; correct PDF; no clipping/overlap; links work; one-page template exactly one page.
Security: cross-user access denied; secrets protected; documents treated as untrusted; AI outputs validated.
