# UI/UX Wireframe Specs

Visual direction: Apple-inspired, not an Apple clone. Spacious, refined typography, subtle borders/shadows, restrained animation, accessible and responsive.

Pages:
Landing, Auth, Dashboard, Resume Upload, Resume Health, Resume Studio, Job Analyzer, Match Report, Tailoring Studio, Career AI, Recruiter Discovery, Outreach Composer, Application Tracker, Settings.

Resume Studio desktop:
Left = sections/issues.
Center = live A4 resume.
Right = suggestions/evidence.

Mobile:
Tabbed editor + sticky preview/export action.

Required states:
Loading, empty, error, success, disabled, focus.

Accessibility:
Semantic headings, keyboard navigation, visible focus, reduced-motion support, adequate contrast.
